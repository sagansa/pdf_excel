## How to Run the Server

__Option 1 — Use the run script (easiest):__

cd admin_backend
./run.sh


__Option 2 — Manually activate the venv first:__

cd admin_backend
source venv/bin/activate   # this makes `python` available
python server.py


__Option 3 — Use the venv's python directly:__

cd admin_backend
./venv/bin/python server.py
